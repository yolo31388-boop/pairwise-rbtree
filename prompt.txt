【bug 报告】红黑树插入/删除后性质被破坏，帮忙修。

项目：Python 实现的红黑树（标准库），支持 insert / delete /
search / inorder / validate（自检 5 条红黑性质）。带 pytest 测试。

复现：
python -m pytest tests/test_rbtree.py -q 有失败，典型症状：
1. 连续插入后 validate 报性质破坏（红色节点的子节点也是红色 /
   各路径黑高不等）——插入修复的分支判断错位
2. 删除后 inorder 缺失元素、树失去有序性或黑高不等——
   删除时"后继替换 + 修复"两步有一处处理错
3. 大量随机插入删除混合后 validate 偶发抛异常——
   说明节点指针/颜色在修复过程中被改坏

原因猜测：
插入修复（case 1-3）有一个分支条件反了，删除修复的
兄弟节点 case 处理错，导致旋转/着色后性质不守恒。

要求：
- 先理清"旋转方向 + 着色时机"再动手，别瞎试
- 别改测试、别用"删除后重建整棵树"糊弄
- 修完 python -m pytest tests/test_rbtree.py -q 全绿
- 最后自己跑 1000 次随机插入删除，validate 必须稳定通过
